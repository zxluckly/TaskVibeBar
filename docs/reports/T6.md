# T6 交付报告（主 Agent 直接实现）

日期：2026-10-23
范围：显示区域自定义（靠左/靠右吸附 + 水平偏移 + 最大宽度 + 模块显隐）与悬停背景颜色/透明度。用户要求快速开发，由主 Agent 直接实现并自测，未再拆子 Agent。

## 一、变更

| 文件 | 说明 |

| `src/TaskbarStrip.cs` | `SetHoverStyle(color, opacity)`；悬停目标透明度可配；自定义颜色/主题色只取 RGB，透明度单独控制 |

## 二、构建

`build.bat` 退出码 0，0 error / 0 warning；`bin\VibeBar.exe` 与 `bin\VibeBar.Cli.exe` 均生成。

## 三、自测

| 项 | 结果 |
|---|---|
| 吸附 | `ui.anchor=left, offsetX=200` 后宿主移到任务栏左侧（实测 x≈160，受任务栏内边距影响）；切回 `right, offsetX=8` 后回到托盘左侧（gap≈7px） |
| 偏移 | `ui.offsetX=60` 启动后宿主整体左移；`offsetX=8` 恢复默认 |
| 模块显隐 | `showAgent=false` 时任务栏只剩额度/Git，面板不显示会话区块；`showAgent=true` 恢复三段 |
| 设置窗口 | UIAutomation 读到偏移 60、最大宽度 420、模块勾选、颜色 `#FF8800`、透明度 47%、实时预览；保存按钮可调用 |
| 保存往返 | 设置颜色 `#123456` 并保存后，`settings.json` 的 `ui.hoverColor` 持久化为 `#123456`；`hoverOpacity` 保持 120 |
| 颜色校验 | 非法颜色/非整数偏移会在保存时拦截（代码路径已复核） |
| 默认恢复 | 最终配置恢复 `offsetX=8`、`hoverColor=""`、`hoverOpacity=235`、三模块全开 |
| 面板 | 悬停面板正常显示额度/Git/会话区块；宿主不抢焦点（沿用 T1–T5 逻辑） |

## 四、注意

- 靠右时偏移从托盘左缘算，靠左时从任务栏左缘算；偏移值以任务栏父客户区坐标换算，实际屏幕像素可能因任务栏内边距/DPI 与设定值略有差异，以目视为准。
- 透明度 100% 为完全不透明，0% 为悬停也完全透明（仍保留 1/255 的鼠标命中层）。
- 自定义颜色为空或勾选「跟随系统主题色」时使用主题色。
